## 真实来源和权限

`server/sourcecatalogpolicy.js`核固定47e358世界manifest的实际21714B/SHA、entities086作者manifest实际854B/SHA，再产生模块私有WeakSet品牌的41角色定义。构造器拒普通/克隆/自称valid策略，getter不执行。固定tuple与`fixed-copy-resources-1`绑定，不跟随latest。manifest自报摘要不能替代这两项代码锚；实际全部叶对象另行读回。

只允许真实非强制改密态管理员登记和完整复制来源读取；普通作者没有完整复制权。注册与所有R2 await/流段/最终提交重新查账户、epoch；每次加载也复查SQLite记录和角色对象，不能凭hash、sourceRef或APPROVED授权。只承接固定内置来源，不允许作者上传其它游戏源，不赋管理员跨作者草稿权限。

## 实际持久链

- `InstalledSourceCatalog`用账户同DO的真实`storage.sql/transactionSync`，表`installed_sources/source_operations`记录固定definition、物理root、长度、创建信息及永久actor/key请求摘要与epoch收据；不存秘密或源正文，不用Map代持久库。
- 实际41输入合计**57,943,821B**，单最大43,308,095B。不能放进16MiB普通单对象门；受控bootstrap角色按1MiB块置R2`installed/<registryId>/<sha256>`，root为规范UTF8 `dragon-installed-source-index-1`。每角色逻辑长度/SHA必须等固定manifest角色；读取逐对象核实际size、流总长、SHA，再核完整角色SHA。不是etag或客户端校验成功标志。
- root最多1MiB/块最多4MiB/总角色最多64MiB、每角色最多64块为本端口有限运维边界，非游戏容量或线上CPU/内存/SLA。每次重建读取全部角色；不宣称满足高并发或免重复验证性能目标。
- 验收后同SQL事务写来源行和操作收据；同key并发只一行/一收据，失败回滚两者。已有登记只可相同index重放，不以新key改根；同key异有效根409。记录definition与当前服务策略不符409，不修复/重贴新版本。
- 重启后以持久SQL记录＋受信固定策略＋重新读取所有R2字节产生**新内容捕获**；旧内存品牌不能由DTO恢复。`readWeb`每次调用仍查捕获时会话/epoch与登记行，只返回已登记角色的独立字节副本，供未改`createPinnedCopyLoader`/共同源、实体、copy和内容差异门使用。捕获不是Game作者授权或运行报告。
