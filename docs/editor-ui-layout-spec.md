# 编辑器工作台 UI／布局规范（全模块强制）

> 适用范围：`editor-ui/` 全部现有及新增页面；仅编辑器展示层，不适用于玩家／Trial Canvas，不修改玩家 `server/public/style.css`。
> 用户确认的长期默认：后续模块直接遵守，不每次询问。特殊情况由用户单独提出。
> 本文是布局／列表细则维护源；架构与边界见 [AGENTS.md §3](../AGENTS.md#3-展示交互与文档职责)。旧 34px、自造主题／表格皮肤等条款已撤销。

## 1. 默认组件与页面骨架

- 全部使用 Element Plus 默认主题、默认组件、默认 size、繁体 locale；颜色、控件高度、字阶、边框、圆角交给默认 `--el-*`，不覆写皮肤。
- 表格 `ElTable/ElTableColumn`、分页 `ElPagination`、弹窗 `ElDialog`、表单对应默认控件、按钮 `ElButton`。按组件路径引入，同时在 `main.js` 引入组件 CSS，不加 UI／图标依赖。
- 自定义 CSS 只管布局、间距、宽度、溢出和资源内容。控件同高靠默认 size，不另写 34px 或全局高度变量。
- `.workbench` 占视口且整页不滚；主区、面板、数据区均正确传递 flex 高度和 `min-height:0`。标题只保留当前模块 `h1`，不另加重复副标题。
- 面板的显示布局只能匹配可见状态（如 `#generals-editor:not([hidden])`），不得覆盖工作台 `[hidden]` 的隐藏；修改任一面板须回归其它模块不占空间。
- 隐藏面板不得因共享 busy／副本重读反复挂载大量表单、选项；按需挂载重型内容时保留面板组件及控制器／本地未保存输入，不得以卸载整个组件造成编辑丢失。

## 2. 顶部提示与工具栏

- `.page-line` 左操作提示、右目前草稿；单行溢出省略，草稿不另造胶囊。
- 工具栏固定在数据区上方，不随表体滚动；flex 行垂直居中，间距交给容器 gap，不用顶边距下推控件。
- 保留中文／繁体文案、既有 id／data-* 协议；不以重排组件为由删除测试／控制器选择器。

## 3. 加载反馈

- **统一图形，不等于一律全局遮罩。** 无真实进度的数据加载使用 Element Plus 默认 Loading，共用 `loading.js` 的蓝色四圆点旋转，不显示等待文字，不用按钮转圈替代，不造各模块专用动画。
- 页面级加载走工作台唯一全局入口；全局 API 请求计数与对应动作 busy 合并，并发最后一个请求／响应正文结束才恢复。每次点击均应及时显示反馈，不允许重型同步渲染先卡住页面，再出现 loading。
- 弹窗／局部数据加载先显示所属容器，再在其内容中央显示共同 Loading；仅遮住所属区域，不触发全局遮罩。真实多批次导入走 `ElProgress` 与已完成／总数，不叠加 loading；现行「从内置游戏导入武将」为服务端单次原子覆盖，没有批次进度，确认后走全局 Loading，含最终重读。内部请求与动作明确传递 `feedback: 'local' / 'progress'`（默认 `'global'`），包括最后保存重读；反馈范围不改变鉴权、busy 禁用、请求或错误语义，成功／失败均清理。
- **完整复制弹窗（用户批准）**：窄版加高、屏幕居中（最大宽440px，小屏两侧留16px）；共用四圆点Loading放在弹窗内进度文字上方，不在背景重复播放全局动画，不显示底部说明。保留实际文件数及不定进度条，不新增百分比；执行中阻塞背景、Esc和遮罩点击均不能关闭，失败保留原因及确认按钮。仅切换动画展示位置，不修改请求计数、busy、复制协议或错误恢复。
- **检验窗口（用户批准，同完整复制思路）**：`PublishPanel`共用检验/提交弹窗采用窄版加高居中，四圆点Loading放在内容上方，不叠全局Loading；去掉底部耗时/可切页说明。保留真实检验层及错误明细，长明细在弹窗内部滚动；执行中不能关闭，成功沿既有流程自动关闭，失败停止动画并保留明细与关闭按钮。不改变检验、票据及上架规则。
- 本地分页／排序即时完成，不伪造延时或加载；若切页需要请求，必须接同一入口。图片／音频的懒加载不阻塞整页。
- 多步动作按实际完成批次更新进度，不伪造百分比；结束说结果，失败保留已完成数量并说明原因及可做什么。
- **游戏删除例外（用户批准）**：不叠加任何Loading，在同一确认弹窗动态显示「建立栅栏→清理游戏文件及公开入口→核对回执/重读列表→完成或失败」。动作、两次写请求与最终重读均走`feedback: 'progress'`；四组范围只按回执标完成，不虚构逐表百分比。原「存储字节」改为「游戏文件与公开入口」；失败显示原因并保留重试入口，旧服务pending回执不能显示删除完成。

## 4. 表格与分页（统一默认）

- 表头固定，表体在剩余数据区内部滚动：有高度约束的 `ElTable height="100%"`，外围 flex 数据区 `flex:1;min-height:0;overflow:hidden`；不靠整页面滚动或自造 sticky 皮肤。
- **固定列宽优先（用户批准，全部编辑器列表通用）**：按内容长度及表头排序符所需空间配置紧凑列宽，读／编辑态保持一致；单元格内输入框、数字框、头像按钮等不得撑大固定列宽。操作列在其 180px 最小宽度基础上吸收剩余空间；可用宽度足够时不产生无谓横向滚动，窄屏不足时允许表格内部横向滚动，不强压固定列或让整页横向溢出。
- 武将管理已批准列宽：序号 60px、头像 80px、姓名 120px、字 100px、号 100px、势力被灭被俘 140px、城塞战／野战／水战／武力／统率／政治各 120px，合计 1420px；操作列使用剩余宽度（最小 180px）。其它模块不照搬这组武将专用数值。
- **所有列表使用 Pagination，不使用瀑布流、无限滚动或滚到底追加下一批。** 当前页表体内滚动不等于瀑布流。
- 共用 `ListPagination.vue`，默认每页 **25** 条，可选 **25／50／100**。包含总数、页码、上一页／下一页和 **jumper 可输入页码跳转**；不启用自造背景／小号样式。窄屏允许分页布局换行，但不得把分页挤到屏外。
- 分页位于数据区下方，不随表体滚动。空结果总数为 0；末页不足一页照实显示，页码不能落在不存在的页。
- 搜索／排序作用于完整数据，再分页；搜索、排序、调整每页条数回第一页。序号按完整筛选／排序结果连续编号，不每页从 1 重算，不当身份／槽位。
- 复用 `pagination.js` 的 `usePagination`；切页／筛选／排序后表体回顶部。切页不自动保存编辑值。
- 已有 copy DTO 仍按原控制器合同读取，再做本地分页，不为 UI 分页改造后端接口／鉴权／存储。将来服务端分页的总数与排序须遵接口合同，不能只排序当前页。

## 5. 操作列（城池据点参考为准）

- 复用 `ListRowActions.vue`：只读态普通默认 **「編輯」**；编辑态同一行依次普通默认 **「保存」「取消」**。
- 不设 `type="primary"`，不改成 link／text／自造图标，不另做固定在右侧的悬浮操作列；操作列作为表格末列随表横向滚动。
- 统一操作列最小宽度 180px，容纳两个默认按钮；同行控件垂直居中，使用相同默认 size，不改按钮高度、颜色或边框。
- busy 时按钮禁用，权限／编辑锁继续服从既有控制器；取消不写入，保存失败保留可修正状态，成功按既有合同重读后显示新值。
- 其它业务动作仍须表达真实语义；需要例外时由用户另提，不能默认为某一模块换一套操作视觉。

## 6. 头像选择弹窗

- 编辑态点击头像立即打开弹窗；目录按需读取，在弹窗内容中央显示共同局部 Loading，不触发全局页面遮罩。重开可复用当前游戏目录。copy弹窗仅取共享资源描述（`?usage=0`），不为未显示的使用标记读取整份旧草稿；完整目录一次获取、PNG按页懒加载。接口与旧模式边界见[轻量头像目录](editor-general-definitions.md#copy头像目录轻量读取现行)。
- **固定每页 25 张**，共用可跳转分页，不显示可变页大小；筛选完整目录并回第一页。当前共享目录文件名／资产 ID 为数字 `0..620`（含255），先按数值升序排列（`0、2、10` 而非 `0、10、2`），再分页；排序自身不改写存储 ID。实际文件／资产重编号及原生byte边界见[画像资源决定](re-notes-portrait-reader.md#现行web准入与原证边界)，旧p目录仅属历史。只挂载当前页缩略图，保留该页图片原生懒加载，不因滚动渲染其它页。
- 「無頭像」是独立选择，不占 25 张配额。选择跨页保留；确认只写本地编辑表单，须再保存武将才持久化；取消不保存。
- 默认 `ElDialog` 从打开时即预留完整尺寸：宽 `min(900px, 94vw)`、高 `min(800px, 90vh)`；Loading、错误、空结果及末页不改变外框大小。随视口限制宽高、内容网格自适应；支持右下角调整大小，仅内容区内部滚动。不覆写默认皮肤。
- 分页整组右对齐；底部「確定／取消」同一行整组右对齐，并保持可见，不把对齐样式扩散到其它列表。

## 7. 枚举、保存与文案

- 枚举显示可读名称；未知保留「数字（未知）」，不隐藏或重写值。名称依据原始证据，例如据点 type 0–4：大都市／中都市／小都市／關卡／戰場（`CS:7DF5`；5 首都／6 中立不是合法存储 type）。
- 保存后按既有控制器合同重读；copy 控制器已经重读时，面板不再额外请求一次。不得把旧修订 `verifiedRead` 合同强加到 copy。
- 页面不写科普长段落，保留必要单行说明或帮助入口，不贴无助于用户的原键／摘要。

## 8. 交付自检

1. 全新隔离浏览器验证实际构建资源，至少 1024×600、1440×900、1600×1000，固定列宽再加足够宽的视口（武将为 1920×1080）：整页不滚，表头、工具栏、分页固定，表体真实滚动；读／编辑列宽不变，宽屏无多余横滚，窄屏固定列及操作可横滚访问，编辑控件不撑宽。
2. 首次／重复页面加载立即显示全局动画，头像弹窗先显示并使用中央局部动画，多批次导入显示真实进度条（含最终重读），不叠加全局 loading；单次内置武将覆盖则使用全局 Loading；失败清理、保留真实结果，无重复请求，不把本地翻页伪装成异步加载。
3. 默认 25 条、末页、上一／下一、页码跳转、页大小、全量筛选／排序、连续序号、空结果与页码收敛全部核对。
4. 两模块操作按钮外观／尺寸一致；取消零写入，保存只发预期字段且重读显示新值，切页没有隐式写入。
5. 头像每页最多 25 张，完整目录数字自然排序后分页，未访问页不挂载／下载；Loading／失败／加载完成／筛选时外框同尺寸，分页及确定／取消右对齐，跨页选择／筛选／确认／取消及窗口缩放有效。
6. 所有非当前模块隐藏且不占布局；隐藏重型内容后重新进入，控制器输入与本地编辑行仍保留且零隐式写入；console／pageerror／意外请求检查；合成 API 夹具、真实后端、生产验证分开报告。
7. build 后 check，主动 LSP＋session `mode=all`，语法／diff 及适用控制器回归；超时或空缓存不算通过。

## 9. 实施边界

本规范长期适用于全部编辑器模块，不自动授权整仓集中迁移。实际实施范围由当前用户任务决定；后续修改对应模块时直接统一，无须重复确认默认要求。各批次改动／验证记入 checkpoint journal，不将未迁移模块写成已完成。
