## 武将生命周期（用户澄清+攻略双确认）

- **无登庸、战斗中不被杀**；俘虏关监狱，每月30日随机脱逃
- 己方武将被抓/打散失踪→某个月初自动回归
- 势力灭亡时君主/部分武将固定自杀(张任/曹操)，其余被俘或流散
- 流散武将随机再就业：领土越大、武将越少的势力吸引力越大(S/L可刷)
- 固定剧情投奔：張遼&陳登→曹操(呂布亡)、張郃→曹操(袁紹亡)、趙雲→劉備、馬超→張魯
- 新武将随时间加入的只有刘/曹/孙三家(200年周仓关平→徐庶诸葛亮庞统马良马谡)
  → 即 SINARIO 武将 +0x18 出场倒计时/+0x19 投奔势力字段的用途！
- 隐藏属性：城塞攻防(荀彧/司马懿/程昱/诸葛亮/庞统=10)；武将对话暗示特长(TALK.DAT)

## 属性与战斗

- 统率=守城/城塞战主属性；武力=野战主属性；政治=内政外交；水战东吴加成
- 战斗即时制：前左中右后军+大将，阵型+攻击/突击/防御指令(BATTLE.*资源)
- 攻城需耗费兵力+士气开城门；攻下后城兵归己方；城兵数只能缓慢自动恢复

## 内政经济

- 发展度 ±200：正→生产力/城兵数自动涨；负→萎缩。防灾过低→火灾暴雨灾害
- ★税率<30% 据点稳定发展(无需内政官)；>30% 停滞转负增长。推荐 20~28%
- 征兵次月生效变预备兵；北骑兵/中步兵/南弓兵(按地理)
- ★财政连续负3个月→未出征部队消失+信赖大降(对应调度器灭亡判定？[si+21]语义候选)
- 兵团每日耗钱粮，行军消耗>驻扎
- 军团回首都解散重组：兵数保留、士气重置200；兵力提升只能靠解散重组

## 外交

- 使者政治<13 无效(花再多钱关系不动)；≥13 才有效，15 半年恶劣→良好
- 治理治安需政治≥10，≥13 效果显著
