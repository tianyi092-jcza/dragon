# 單 cell 地圖：設計、舊圖轉換與切換門檻

**產品決定**：Web 編輯地圖每格只有一個值，不可堆疊。道路下面沒有裝飾，清空不會露出上一件物件。一個據點只占中心格，城牆與周圍建築不是據點身份。此設計取代新格式中的裝飾實例／永久組合，不改 DOS 行軍規則。現行 `map-atomic-catalog-contract.md` 的舊圖層行為仍適用尚未遷移的來源。

### 一份格表，不是四張疊圖

`(x,y) → (y-minY)*width + x-minX → 一個材料編號 → 空／裝飾／道路／據點`。編輯值為 `0..255` 或空；檔案用無號 16 位小端序（空值 256，0、95、255 都是有效素材）。`464×336` 無論全空或全滿，格表正文都為 **311,808 bytes**；JSON 輸送用 base64，非逐格 JSON 物件。空格顯示共用底圖 95，明確繪製的 95 不等於空。四季使用同一格表、各季圖集；若日後配置不同季節圖號，應在素材表映射，而不是重複存在每格。

| 保存 | 不保存 |
| --- | --- |
| 唯一格表、帶負原點的邊界；據點中心與穩定綁定；道路邊的端點、路徑、通行種別與既有規則欄位 | 裝飾實例 ID、層序、被遮住的裝飾、持久組合、道路／據點的第二份圖塊 stamp |
| 已生效的規則地理及小地圖地理，遷移時每格合併為一個位元組的兩個 2-bit 值 | 不從頂層顏色重新猜水陸；這些值不是可再次露出的素材。小地圖圖片按鈕另議 |

素材類型與路徑可達性不是同一件事。中心 `CB..D3`、道路／門磚與其他原子按既有素材與准入合同；`BE` 原用途未定，不新認證為道路。單格路紋本身不是邊。保存路城改動時，從尚未被道路使用的道路格追蹤；唯一連接兩座已綁定城市城門的鏈，經 `buildRoad` 認證才登記。已登記邊保留，不因另存而換 ID。保存以整批實際編輯分流：只改裝飾（含清除、搬移、複製），不因數量觸發路網檢查；動過路磚、中心或綁定，即使可從旁路繞行，也要檢查各路段與整網。未屬有效道路的路磚標紅並阻止這一批寫入；城市可保留尚未接路的城門。已綁定且沒有任何道路的據點允許保存，不算斷路；有邊的路網仍檢查連通性，未接通的路磚不得因這項例外而保存。正式編譯也檢查殘段，純裝飾可存不代表可發布。已有邊仍須通過 `buildRoad` 的門距、方向、連續、交叉等限制與既有連通校驗。分類依據見[原子合同](map-atomic-catalog-contract.md)、[遷移原證入口](re-notes-editor-map-admission.md)。

### 實施順序和驗收

1. **離線轉換與核對（已實作）**。從已保存的模板或指定遊戲 copy 唯讀取一份已核摘要的來源。用舊合成器取得最終素材；依實際 stamp 占格區分空格與明確鋪設的 95。打散多格、丟棄遮擋與組合；保留路網／中心綁定與獨立地理。舊無 policy 但底層逐格明確為 95 的圖可以轉；非全海或未知底圖暫拒，不猜。中心與 binding 不符、路徑穿越非路格、結構或幾何不合法則停止。輸出不是新遊戲：只含 map 與驗證收據，**不替換整份模板／遊戲資料**。
2. **工作台及保存（已接普通裝飾與顯式轉換）**。基礎／遊戲地圖的「轉為單格地圖」只在畫面預演；按保存才送 `cell-convert`，伺服器從持久源重算，沒有傳整張格表。轉換丟棄舊裝飾實例、永久組合與非原子定義。新格式走 `cell-paint`、清空、撤銷及權威重讀，沒有舊圖層操作；素材庫保留道路、據點與據點組。路磚先寫入單格，服務端保存時認證門到門的路鏈；中心放置後須綁定，整組按配方展開為獨立格並一次撤銷，不產生永久組合。道路和中心不接受裝飾筆刷。右鍵中心可綁定／解綁；選格 Delete 或右鍵「清除」先確認。清中心只解綁並移除落點，不刪城檔，有相連道路時拒絕；清路格同時移除經過它的邊，保存仍須通過路網校驗。未顯式轉換或尚未保存不會改寫資料庫。`openCellDecorEditor` 已支持記憶體解碼一次、單筆多格裝飾替換／清空／撤銷；筆刷先檢查整批，遇到路城或越界不留前綴。同 ID 不改動遷移地理；改為新素材時按原子素材 policy 重算該格地理，撤銷恢復精確前值。Shift 點選及右鍵框選建立暫態單格選區。鎖圖後可搬移裝飾、路磚及據點中心，支持整批平移；不得覆蓋未選取的道路或據點。中心保留綁定及章節槽，移動中心不連帶搬走門磚。放手立即按新格面校驗並標紅相關道路，保存時由服務端再驗。拖動時原格呈空，落地後選區跟隨目的格；Shift 拖動只複製裝飾，不複製邏輯路城。兩者保留格值與規則地理。Ctrl+C/V 複製的是裝飾素材及相對位置，按普通筆刷規則貼上，不複製道路或中心身份。筆刷直接展開成格，清空不復原歷史。撤銷還原操作前的值及相關規則地理，不存第二層。移除組合、圖層調序、裝飾實例 ID 操作。據點綁定、端點及候選道路由服務端從格與既有規則重驗；不可只信前端導出的邊或平面。驗收含斷路／重連、滿圖連續替換與整筆撤銷、保存後重讀。
3. **建局／發布與切換（隔離正式鏈已驗，生產舊包待核）**。`composeCellPlane` 為共同校驗與編譯提供平面，`compileGameSource` 照常檢查路網、章節與節點。模板與 copy 的命令入口已接。單格源送審、發布、正式 reader 開局與跨章存讀已在隔離環境驗證；不代表生產在架包或全戰役已驗收，實測範圍見[交接日誌](checkpoint-journal.md)。同一份內容不可同時保留兩種 live 地圖。保持章節、武將、據點主表、素材庫、兼容性資產及路網規則資料。驗證舊／新源的正式路網、四季外觀、遊戲開局、行軍及存讀；不能把地圖四平面相同當作全遊戲發布驗收。
**雙工作台驗收**：基礎地圖與遊戲的「地圖管理」共用單格編輯行為；變更時兩端都要驗轉換預覽／撤銷、裝飾直接保存、路城拖放／斷路標紅與拒寫、修復後保存重讀。權限、讀寫對象不同：前者僅改系統模板，後者僅改所選遊戲副本（另驗章節鄰接與發布）。同步指規則與操作一致，不互相覆蓋資料，不自動轉換已上架包。

4. **真庫遷移（未執行，另行授權）**。先保護未保存頁面，不能藉重新載入或重啟伺服器處理 413。分別盤點系統模板和每份遊戲 copy；先一致備份，在副本走完整演練。正式寫入核對版本與摘要、禁止並行寫、交易後獨立重讀；衝突列具體對象／座標。歷史上架快照不改、不自動重發、不遷移使用者存檔。

### 重做離線演練

從倉庫根執行。輸出請用系統臨時目錄下**尚不存在的子目錄**；命令沒有 apply 選項。`report.json` 記來源身份、邊界、大小、新檔 SHA 和四項逐格比對結果。檔案大小口徑只涵蓋地圖，不含章節與圖集。

```sh
node --test tools/verify_cell_map.mjs
node tools/convert_cell_map.mjs --template-sqlite <一致備份.sqlite> <新目錄>
node tools/convert_cell_map.mjs --copy-sqlite <一致備份.sqlite> <另一新目錄> <遊戲UUID>
node tools/convert_cell_map.mjs --source-json <模板或遊戲源.json> <另一新目錄>
```
