# SEA-GROUND-1：全幅海域基底与地面轮廓

## 1. 决定与范围

**Web 产品决定（非原版机制）**：用户在第二阶段 v41 后明确要求全图默认使用原 tile95 海纹理；隐藏装饰、道路、据点后仍是海面；取消手工陆／海／河／湖及单格／范围填海。小地图只显示地面形成的陆地轮廓、海域、道路和据点，不显示其它装饰的具体图案。用户随后澄清：不是所有装饰变陆地；一级固定「基底／装饰／道路／据点」，二级分类可以调整，但不得改变一级归属或地面语义。

本文件是海底与地面轮廓合同的唯一详细维护源，取代第二阶段设计旧 §8 的单格／矩形填海方向及新模式的水域组合小地图开关。后续用户批准[ATOMIC-CATALOG-1](map-atomic-catalog-contract.md)：取消本页原四个一级库导航，现为240单格展示／256底层身份、七个末级分类且无素材悬停，固定春季并隐藏据点所属配色变体；四层合成语义及图层工具保留。用户界面统一称「底图」，未放素材处自然露出，不需要逐格铺海。旧版验证收据、原数据与原机制结论保留其历史范围，不改写成新模式证据。

- 固定 384×256／192 据点槽及原道路支持域，不开放新路桥、移城、扩容或未知配方。
- 不重开 Trial API。共同编译结果仍交正式玩家 pack／environment／scenario 加载器。
- 不自动迁移生产、已有持久模板、旧 copy、已发布包或内置登记源。普通新建和完整复制仍捕获同一份当前系统模板快照，不变成全空海图。

## 2. 三种输出与稳定语义

```text
全幅海底95 ──装饰字节──道路──据点 → terrainBytes → 同一玩家引擎
     └────仅地面占格的并集──────→ minimapGeography → 海陆轮廓
道路 geometry ─────────────────→ roadMask ──────→ 小地图道路
据点状态 ──────────────────────────────────────→ 玩家据点绘制
```

- 显式 `map.base.policy = "sea-ground-1"`。该模式要求全部 `terrainRef=95`、`geography=1`；未知 policy 或不一致基底拒收。旧无 policy 源仍按旧合同编译，不能用新规则改写其身份。
- `web/src/content/authoring/mapground.js` 固定 Web 地面 byte 集合，不从可调整的 `category` 名称、像素颜色或目录排序实时推导。旧标为水域的实例／作者水域定义默认不贡献陆地；例如同 byte61 的水系身份不会被当成地面。95 本身不贡献陆地。
- `minimapGeography` 从海开始，只合并装饰中的地面占格。山地、水系、田地、城墙等非地面不增加陆地，也不擦掉下层已有地面；移除／移动地面后重算轮廓。道路、据点不冒充地面。水系不单独画入新模式的小地图；旧 `showOnMinimap` 不影响此输出。
- 捕获重叠素材时保留地面贡献的并集。只有无法从最终字节默认恢复时才保存 `definition.minimapLandMask`（footprint 内的唯一整数坐标，可为空）；拆分单格使用布尔 `instance.minimapLand` 保留贡献。两者属于显示语义，不是原通行／战斗分类。
- `geography` 仍保留水域元数据的独立合成；它和 `minimapGeography` 都不是规则地形权威。`terrainBytes` 保持四层字节顺序，原道路／节点校验和 Scenario 权威不变。绘图不修改源、路线、RNG 或游戏状态。
- 四层归属不从可调整的浏览分类推断。`editor-ui/src/mapcataloglayers.js`保留v41目录的稳定归属及兼容投影；原四个一级TAB和额外海域卡已被[单格库](map-atomic-catalog-contract.md)取代，当前库每个原byte恰一张卡，桥梁／水路并入道路。历史目录身份保留，不能据改名取得规则能力。

## 3. 启用、编辑与持久化

- 新系统模板首次建立：受信转换后调用共同 `enableSeaGroundBase`，再完整验证和事务保存；不会覆盖已存在模板。
- 打开可编辑旧地图：控制器本地暂存一条 `{op:"sea-ground-enable"}`，明确显示「尚未写入／可撤销」。读接口不写库；保存走原接口、权限、预算、摘要及事务，然后重读。一次撤销恢复旧源；再次重读旧源会重新准备预览。未保存离开仍须确认。
- 启用时保留旧装饰、道路、据点和原海状覆盖实例。旧已知非95基底逐格提升为位于装饰最下方的既有原子实例，避免丢掉作者内容；旧未知底层改为本次明确批准的 Web 海底，不声称恢复了 DOS 隐藏地形。旧 waterGroups 的 baseCells 清除，保留仍有实例成员的组。
- `sea-ground-enable` 只接工作区命令路径，严格只允许 op 字段；不加入旧 FixedCopyProfile 的冻结历史重放白名单。幂等启用不产生重复实例，组批仍受128命令／16KiB限制。
- 工作台删除手工地理、单格／范围填海和水域小地图开关；动作适配器也明确拒绝这些入口。旧无 policy 源的底层命令／历史重放兼容仍保留；新 policy 下共同 `fillBase` 拒绝改固定基底。
- 隐藏图层只是显示投影。隐藏装饰／道路／据点时，全图绘制95；只有用户明确隐藏基底本身才允许无底显示。显示副本不能发布为运行源。
- 缺 `mapEditorAssets` 的旧 copy 仍明确拒绝，不以本次启用偷偷回填资源。
