# ATOMIC-CATALOG-1：单格素材库与单层分类

## 1. 用户决定与范围

**Web 产品决定（非原版机制）**：用户在SEA-GROUND-1之后要求素材库全部直接使用原游戏16×16单格图块，不再展示组合样板；取消「基底／装饰／道路／据点」一级库导航及「分类样板／原始历史／我的素材」等库切换，只保留末级分类。后续追加水路、桥梁归道路；底图自然露出，不需要用户理解或手工铺设“海域”；去掉素材悬停说明。

本文件是这轮素材库的详细维护源，替代第二阶段及SEA-GROUND-1中的**素材库导航／默认组合卡／Tooltip**约定。全幅95底图、地面小地图贡献及共同编译仍由[SEA-GROUND-1](map-sea-ground-contract.md)维护。旧v41资源／身份审计和历史验证不是新库的验收结果，也不因本轮展示调整失效。

不包含：自动拆除地图上的现有组合、删除旧定义或实例、新建道路／桥梁／水路、移动据点或自动势力配色、地图扩容、生产迁移。共同组合／拆分能力保留；后继MAP-SPACE-4按用户要求把右键菜单的组合／打散入口暂置禁用，不自动拆旧对象，也不开放新的据点组合工具。

## 2. 现行展示合同

- 底层保留原byte `0..255`全部身份；默认素材库隐藏16个游戏动态所属配色变体，显示240张原生16×16单格卡片，右侧以32×32显示；地图占格仍为16×16。不裁多格样板、不旋转／镜像、补像素或合并相同外观。72／190仍是两个身份，原用途未知。
- 仅七类：**地面、山地、水系、农田、墙体、据点、道路**。桥梁与水路均在道路，不另开类别；同名据点类别不重复。分类只是Web浏览标签，不改地图层、规则byte或小地图地面贡献。
- 原子分类映射维护于`editor-ui/src/mapatomiccatalog.js`。72／190暂列地面供浏览，但不是陆地认证，明确只读；95在水系中保留原始图块参考，实际是自动底图，不提供铺海操作。
- 取消组合样板、历史库、作者库、高级原子库、Web编辑组合等素材导航。图层／属性工具仍保留底图、装饰、道路、据点的眼睛／锁；取消的是**库导航**，不是合成顺序或图层控制。
- 使用默认Element Plus按钮式TAB，七类按4＋3两行全部显示；地图素材库是分页默认的用户批准例外，取消分页，以局部瀑布流分批懒挂载。工作台固定春季、无四季选择控件；四季共用同一份布局，预览直接裁春季原图集，以关闭平滑的2倍像素显示；CSS尺寸32×32，后备尺寸为32×DPR。地图绘制、幽灵、坐标及保存仍使用原16×16格，不随预览放大。
- 素材没有Tooltip、原生title或悬停说明；保留无障碍名称、只读说明及键盘语义，不常驻长名称，32×32图样下显示原byte ID。可放卡支持拖放和Enter／空白键开始、方向键逐格移动、确认放置、Esc取消；只读卡没有放置动作。
- 用户界面称「底图」：未放置素材的位置自然露出底图，不另设海域分类／工具。显示／隐藏与浏览不写内容；显式隐藏底图仍是纯显示控制。

### 2.3 MAP-SPACE-4：地图优先布局与对象菜单

**用户批准的Web产品决定**（截图`pi-clipboard-1eac430f-ea8b-44a3-a137-2bd9170fedc9.png`及后续“折叠导航自适应”“按这个改”）：

- 尽量释放地图面积：移除重复标题、固定中间属性栏及窄屏侧工具切换；状态原并入工作台标题下提示；后继[§2.4](#compact-map-layout)改为工具按钮之后同行，删除待保存启用的长说明，但真实错误和诊断仍保留。文字工具默认两字，新增“100%”为明确例外；功能解释用按钮title，不恢复素材悬停提示。
- 右栏固定紧凑宽度，七类按钮式TAB按4＋3两行，无横向隐藏。未获新增“其它”的分类决定，不另分未知byte；固定春季、240卡／79可放／161只读不变。每卡32×32、下方`ID：<byte>`；每批24项，在素材区内接近底部时追加，切类回顶部，整页不滚。只例外地图素材库，不改其它列表／头像分页。
- 四层眼睛／锁移到地图左下角浮动卡片，可拖动把手或用方向键移动。位置是本地展示状态，不保存入地图；缩小视口时限制在地图可见区。浮层的位置由外部布局容器控制，不覆写Element Plus皮肤，避免默认卡片过渡动画使拖动落点漂移。
- 左侧导航折叠后释放的宽度全部给地图。`ResizeObserver→resize`沿用私有Canvas当前缩放及世界中心，在世界边界作原有clamp，不自动全图。浮层与素材滚动不改变源／计时／RNG。
- 左键选中已有完整对象后，右键或Shift+F10弹出操作卡片；显示类型、对象锚点坐标和完整实例ID。单格原子类型使用既有浏览分类；多格保留“装饰片段”，不按拾取的一格拆掉对象。菜单限制在地图内，Esc／外部点击／选择或地图状态切换关闭。
- 第一行依次置顶、下移一层、上移一层、置底；只对未锁且显示的装饰层开放。置顶／置底是一条`decoration-reorder`命令，direction分别`top`／`bottom`，稳定分区保持选中及未选中各自相对顺序；±1仍是旧相邻交换。只改装饰数组顺序，不跨道路／据点／底图，不修改坐标、定义、地理配方或拓扑。一命令预演／一次撤销／保存重读／票据失效仍走原边界。
- 第二、三行的组合、打散、复制、填充、右旋转、左旋转、左右翻转、上下翻转均禁用；底行对象锁定暂禁用，删除只作用于允许编辑的完整装饰。共用核心能力保留，但本轮不接这些禁用入口。
- **待用户明确**：顶部“锁图”是否禁止拖动、缩放或编辑尚未明确，保留禁用锁图图标，不擅自设定含义。这项不算已实现可用能力。

### 2.4 MAP-SPACE-5：收回顶部留白、紧凑浮栏与100%

**用户批准的Web展示决定**：标注图`pi-clipboard-76dafe5b-e474-43ad-9577-6ca2909cd8c5.png`明确删除长说明，提示接在按钮之后同行、素材栏向上与工具行齐平；后续明确右栏固定宽度、导航折叠的宽度全部给地图、两栏底部齐平，并强调重点收回顶部高度。另批准浮动图层图标正常无边框、悬停出边框且正方形，以及放大／缩小之间增加“100%”。这些决定覆盖§84历史中“长说明保留”和独立标题下状态行。

- 仅地图页采用紧凑壳：顶部导航头56px，主区内边距上4／左右8／下8px，标题后4px即工具行。不改变标题字体或默认控件高度，离开地图页恢复其它模块既有布局。
- 地图主体两列：弹性地图＋固定260px素材栏，中间8px。工具按钮／状态在地图列第一行，素材分类从同一高度开始、右栏跨满两行；地图紧贴工具行下方，底部与素材栏对齐并只保留8px外边距。导航折叠／展开只改变地图可用宽度，保留当前视野中心／缩放；全图模式仍等比显示，不横向拉伸地图掩盖留边。
- 按用户后续标注，工具按钮组与地图左边缘对齐，状态区域及文字与地图右边缘对齐，两者保持同一行。状态含未保存、保存结果和`run()`异常，长文本省略并可用title查看。窄屏只在按钮组内横滚，状态仍留在可见区，不换出第二行。删除海底启用的常驻长说明，不删除未保存守卫或真实错误／诊断／重试入口；地图数据与保存时点不变。
- 素材仍七类4＋3两行、三列32×32预览＋ID、24项分批懒加载；只压缩容器间距及留白，不缩小图样、改分类或放置许可。
- **用户明确批准的局部外观例外**：仅地图浮动图层栏用Element Plus默认size的text图标按钮，宽32px匹配默认高32px；正常边框透明，hover／键盘focus-visible用默认`--el-border-color`显示边框。卡片内边距4px、组间4px、组内2px；不更改其它按钮的边框、padding、尺寸或主题。浮层仍可拖／键盘移动，不另占地图高度。
- “全图／放大／100%／缩小”顺序固定。100%沿既有zoom动作把当前倍率还原到1：原16px格显示为16 CSS像素，DPR只增加后备分辨率，右侧预览仍32px；保世界中心并沿既有世界边界clamp，不自动全图、不改变地图源、不触发保存。顶部锁图及其它暂禁用能力仍按§2.3，不因本轮新增缩放按钮而开放。

## 3. 准入、状态与保存

- `projectAtomicSpriteCatalog`复用既有`projectSpriteCatalog`的严格原子身份检查，只投递DTO。缺失或篡改原子定义不得用同名多格定义替代，卡片保持不可用，不伪造预览。
- 可放byte取v41已获`existing-decoration`支持的原子／完整配方所引用byte并集，共79个；默认库另161个只读，16个所属配色变体仅隐藏展示。未因归入道路／据点／水系或视觉相似而授予规则能力。原资源、v41 JSON及旧定义不修改。
- 默认`createMapCanvas`不注入组合配方，输出仅240单格卡及完整256原子身份DTO；私有组合planner和共同命令仍保留，独立回归显式注入旧受信配方。地图中已有组合／selectionGroups仍能绘制／选中，浏览原子库不重写它们。
- 单格放置继续走一条`decoration-place`及既有控制器→共同预演→服务保存→重读，不新增材质定义，不绕过锁层、权限、会话、预算、未保存离开及票据失效门。保存模板不修改旧游戏；两种创建各取同一份当前模板快照，随后独立编辑。
- 调序方向准入由共同预演及`copyprofile`受限请求白名单共同支持±1／top／bottom；额外字段、非法方向、缺失对象仍拒绝，失败批次不留下前缀写入。
- 玩家仍消费共同编译的规则地形和小地图资产，不采用仅Canvas上叠色的替代路径，不重开Trial接口。只读结构和未知规则继续受原准入门限制。
