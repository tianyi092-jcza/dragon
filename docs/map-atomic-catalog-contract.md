# ATOMIC-CATALOG-1：单格素材库与单层分类

## 1. 用户决定与范围

**Web 产品决定（非原版机制）**：用户在SEA-GROUND-1之后要求素材库全部直接使用原游戏16×16单格图块，不再展示组合样板；取消「基底／装饰／道路／据点」一级库导航及「分类样板／原始历史／我的素材」等库切换，只保留末级分类。后续追加水路、桥梁归道路；底图自然露出，不需要用户理解或手工铺设“海域”；去掉素材悬停说明。

本文件是这轮素材库的详细维护源，替代第二阶段及SEA-GROUND-1中的**素材库导航／默认组合卡／Tooltip**约定。全幅95底图、地面小地图贡献及共同编译仍由[SEA-GROUND-1](map-sea-ground-contract.md)维护。旧v41资源／身份审计和历史验证不是新库的验收结果，也不因本轮展示调整失效。

不包含：自动拆除地图上的现有组合、删除旧定义或实例、新建道路／桥梁／水路、移动据点或自动势力配色、地图扩容、生产迁移。保留共同组合能力及原有选中片段的手动拆分，不等于本轮开放新的据点组合工具。

## 2. 现行展示合同

- 底层保留原byte `0..255`全部身份；默认素材库隐藏16个游戏动态所属配色变体，显示240张原生16×16单格卡片，右侧以32×32显示；地图占格仍为16×16。不裁多格样板、不旋转／镜像、补像素或合并相同外观。72／190仍是两个身份，原用途未知。
- 仅七类：**地面、山地、水系、农田、墙体、据点、道路**。桥梁与水路均在道路，不另开类别；同名据点类别不重复。分类只是Web浏览标签，不改地图层、规则byte或小地图地面贡献。
- 原子分类映射维护于`editor-ui/src/mapatomiccatalog.js`。72／190暂列地面供浏览，但不是陆地认证，明确只读；95在水系中保留原始图块参考，实际是自动底图，不提供铺海操作。
- 取消组合样板、历史库、作者库、高级原子库、Web编辑组合等素材导航。图层／属性工具仍保留底图、装饰、道路、据点的眼睛／锁；取消的是**库导航**，不是合成顺序或图层控制。
- 使用默认Element Plus分类Tabs及25／50／100分页和jumper，仅挂当前页。工作台固定春季、无四季选择控件；四季共用同一份布局，预览直接裁春季原图集，以关闭平滑的2倍像素显示；CSS尺寸32×32，后备尺寸为32×DPR。地图绘制、幽灵、坐标及保存仍使用原16×16格，不随预览放大。
- 素材没有Tooltip、原生title或悬停说明；保留无障碍名称、只读说明及键盘语义，不常驻长名称／ID。可放卡支持拖放和Enter／空白键开始、方向键逐格移动、确认放置、Esc取消；只读卡没有放置动作。
- 用户界面称「底图」：未放置素材的位置自然露出底图，不另设海域分类／工具。显示／隐藏与浏览不写内容；显式隐藏底图仍是纯显示控制。

### 2.2 固定春季与中立据点素材（ATOMIC-SPRING-NEUTRAL-3）

**用户批准的Web展示决定**：移除春夏秋冬选择，地图与素材只显示春季；编辑同一布局后自然供四季使用，不需要作者逐季编辑或确认。带势力的据点外观由游戏动态决定，不作为作者的素材选项。本轮不新增或改写游戏着色规则。

- `BaseMapPanel.vue`移除季节控件／样式，两workbench不再暴露`season`动作，私有图集加载器使用既有春季默认值。保留四季图集和共用Canvas／loader的四季能力，不删除秋冬资源、不创建四份地图、不额外发起四次保存。
- 仅从默认`catalogItems`隐藏`203,204,206,207,209,210,232..241`共16项，`catalogAtoms`、原定义、图集、旧地图引用及v41身份目录全部保留。中立中心保留`205,208,211`；`222..231`是中立／其它非玩家所属共用的部件族，并非仅中立专用，保留其中原墙体分类。其它通用据点部件不随中心色组误删。库总240项，79可放／161只读，其中据点30项仍全只读。
- **复核原证而非按截图颜色猜测**：固定`Dragon/KI.EXE` SHA `fffeba985231cda4d636e93d10f598470b1f691d00275e4aa38e285893d43868`，MZ头200h，`89F0..8AEA`完整窗SHA `11e4ac44e6a7104365b62f752a786d68a84419be04c8bd52a47a7e0f40de5e4c`。`8A3F..8A63`保留旧中心三色组：C01=18h取+2，否则C01=CS:CFF取+0，其它取+1；`8A66..8A74→8AD1..8AE9`使222..241在十对间按是否玩家选择。当前正常玩家域下，中立使用222..231；不外推非法玩家身份。完整来源／调用与角块边界唯一维护于[准入§2.1d](re-notes-editor-map-admission.md#21d-原城市着色与部件相对位置复核g10g11g12未开放新放置)，本轮只读重核指令和19项来源回归，不修改原机制。
- 自动共用指**一个布局供四个图集解释**，不是烘焙四份独立地图。单元测试将一条放置命令JSON往返，再逐季核同一坐标／原byte绘制且源不变；浏览器核模板与作者游戏均只请求春季、保存仍保留四季描述符。

## 3. 准入、状态与保存

- `projectAtomicSpriteCatalog`复用既有`projectSpriteCatalog`的严格原子身份检查，只投递DTO。缺失或篡改原子定义不得用同名多格定义替代，卡片保持不可用，不伪造预览。
- 可放byte取v41已获`existing-decoration`支持的原子／完整配方所引用byte并集，共79个；默认库另161个只读，16个所属配色变体仅隐藏展示。未因归入道路／据点／水系或视觉相似而授予规则能力。原资源、v41 JSON及旧定义不修改。
- 默认`createMapCanvas`不注入组合配方，输出仅240单格卡及完整256原子身份DTO；私有组合planner和共同命令仍保留，独立回归显式注入旧受信配方。地图中已有组合／selectionGroups仍能绘制／选中，浏览原子库不重写它们。
- 单格放置继续走一条`decoration-place`及既有控制器→共同预演→服务保存→重读，不新增材质定义，不绕过锁层、权限、会话、预算、未保存离开及票据失效门。保存模板不修改旧游戏；两种创建各取同一份当前模板快照，随后独立编辑。
- 玩家仍消费共同编译的规则地形和小地图资产，不采用仅Canvas上叠色的替代路径，不重开Trial接口。只读结构和未知规则继续受原准入门限制。
