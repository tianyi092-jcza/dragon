# 1．產品、資料與安全合同

## 世界與尺寸（共同核心唯一解讀）

- 不可裁切的原域是 `x=0..383, y=0..255`，16px／格。「不可裁切」指範圍，不禁止原有素材編輯。北、西延伸使用負座標；東、南自然遞增。世界座標、城／路／素材身份、舊城槽序及章節引用均不因平移平面而改變。
- 設西、東、北、南已加格數為 W/E/N/S，各為整數 `0..40`。`minX=-W, minY=-N, width=384+W+E, height=256+N+S`。由邊界反算 `W=-minX, E=minX+width-384, N=-minY, S=minY+height-256`；逐側驗證，不能只驗總面積。最大 `464×336`，含端點 `(-40,-40)..(423,295)`。每次命令只改一側一格；無負債、不借對側額度，縮回才恢復本側額度。不要同時持久化兩套可分歧的真值。
- 緻密索引 `i=(y-minY)*width+x-minX`，先判半開區間再索引；逆轉用 `minX+i%width, minY+floor(i/width)`。擴／縮按世界格重新映射，不能直接截斷陣列尾端。地形、地理、未知底層、群組索引、規則占格、遮罩、小地圖、圖塊與視口逐項分類，世界物件不能再加位移。四季共享布局，新格底圖 95 全海，地理沿既有海底合同；不是裝飾、道路或自動通行。
- 模板、新建、完整複製各自持有獨立快照；取得地圖時繼承已用額度，不重置為可再加 40。模板變更不追改既有副本。舊固定圖可按其明確版本解讀為四側零，不批量遷移；未知版本、缺必要資料或身份不合拒絕，不猜底或截座標。

## 一次編輯的結果

| 對象 | 縮邊處理 | 禁止事項 |
|---|---|---|
| 空海、稠密底圖與按格旁表 | 僅移除裁切條帶，保留區按世界格對照 | 不把原格當新海，不留下舊寬索引 |
| 單格、多格裝飾、組、據點外觀裝飾 | 以完整足跡相交判定；跨界整件移除，清其成員／引用，撤銷整件復原 | 不只看中心、不碎片化、不因裝飾外觀刪城 |
| 有實體綁定的據點 | 裁掉其放置／綁定則列明受影響城；保留主表、穩定 ID、章資料及戰場引用，進入既有未綁定修復流程 | 不刪城檔、不換槽、不自行另找城或合法座標 |
| 道路、門端口、章節鄰接 | 裁越界路段；逐條指出哪個端點、哪段或哪個引用不再合法，禁止作為合法通路；修正後重算、再次認證 | 不自動拉線、跨缺口拼接、重連別城或猜鄰居；不讓斷路通過發布 |
| 未辨識的受影響層／引用 | 預演報出種類、身份與位置並拒絕本步 | 不靜默遺失資料或只改第一章 |

預演與執行共用純命令和同一輸入快照。確認後整批落入工作區，一次撤銷；取消／拒絕／傳輸失敗不寫半批、不假裝儲存成功。影響摘要列出前後邊界、裁切條帶、整件移除數、解綁城名／ID、受損路／引用；錯誤用繁體紅色文字＋原因，不單靠顏色。**確認縮邊不是確認刪除據點**。區分暫存可修狀態、既有模組儲存門、全量發布門：若未綁定或斷路不符合既有保存合同，保留未保存預演並列修復項，修好再存；不得為了展示成功而放寬校驗。乾淨空帶一定能儲存、重讀、縮回。

## UI、權限、請求防呆

- 沿用「遊戲地圖」Canvas／工作台；最終四邊各有獨立 `＋／－`，清楚標示方向。懸停／鍵盤焦點顯示動作與剩餘額度，預覽新增／移除的整行列；移開不留變更。確認顯示實際方向和影響，取消無副作用。零額度禁縮、滿額禁加、忙碌禁重入、無寫權不發送。畫布拖曳、鎖圖、選取與工具按鍵不可互相觸發，按鍵不遮擋既有導航。用 Element Plus 預設元件／預設尺寸、共用錯誤狀態；不新增模組、側欄或玩家 CSS。
- 後端只接受受限操作（方向列舉、加或減），自現有服務端狀態重算邊界、影響及預算；不信任客戶端傳來的新平面、額度、裁切清單或權限。重用現有鑑權、Origin、epoch、遊戲歸屬、刪除栅欄與模組限制；未授權、內置、錯遊戲、陳舊的目標狀態皆不得落錯資料。確認期間切遊戲／修改來源則使該預演失效；失敗保留輸入，網路結果不明先重讀核對，不盲目重送。不得擅增全域 CAS、加大共用路由上限、改全域信任設定。
- 只用已授權那款 copy 做可還原的現場驗收；不能以清庫、刪副本重拷、覆蓋模板、直接 SQL 或改 pin 當成開發捷徑。自動化以 `mkdtemp`／隔離 profile／mock IDB 為預設。附帶產生的維護工件不含帳密、票、玩家存檔或完整私有源。
