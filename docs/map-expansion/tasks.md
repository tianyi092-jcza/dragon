# 2．逐關任務：一關一份證據，不跨關宣告完成

```text
E0 基線 → E1 座標 → E2 北側頁面最小閉環 → E3 四邊 → E4 裁切修復
 → E5 模板與副本 → E6 編譯與顯示 → E7 行軍與 AI → E8 戰鬥與時間
 → E9 正式存讀 → E10 本地發布鏈與結案
```

以下路徑相對倉庫根，檔名是調查入口，不要求拆出同名模組。每關既要有成功案例，也要讓錯誤輸入確實在預期層失敗；失敗先定位，修復後重跑，不可刪斷言。新測試由實作者建立，名稱與命令記在收據，不把計畫中的測試當成現有程式。

### E0｜盤點與保護起點
- 核對 Git 根、HEAD、未追蹤實驗檔與未提交 diff；讀 §223–226，執行北線實驗與相關舊圖基線。列出編輯／編譯／呈現／AI／戰場／存檔／發布對零原點、固定列寬、byte、行指標的消費點。區分圖集大小、原證常數、世界尺寸，勿全域取代 `384` 或 `256`。
- 核實當前服務命令、port、唯一 store、現有副本 gameId／作者／標題、權限與未儲存編輯。確認有可讀回的基線與可逆操作；正式寫入前依驗收帳防護。基線已知 `CHAPTER_CAPITAL`、小地圖 hitTest 曾失敗，重現與分類，不淡化為可忽略。
- **出口**：受影響路徑清單、現場識別與還原方式、實驗和舊測收據；身份不清不能現場寫。獨立只讀工作不因此停止。

### E1｜共同尺寸與索引
- 從 `web/src/content/authoring/{mapextent,maplayers,mapcompile}.js` 收斂尺寸讀取、檢查及世界／局部座標。定義新格式與舊固定 profile 的讀取界線；不要改歷史資料。先交付純命令、海底、按格旁表與舊域不變的證據，不對外開門。
- **出口**：原圖、北西負值、東南正值、四角最大範圍逐格換算往返；零／滿／超額、非整數、反向挪原域、長度不對均拒絕。原圖四季及原三平面相同，原世界物件 ID／座標不變。原始圖集／規則語義未變。

### E2｜先在現有頁面做一個可見閉環：北加一行、縮回
- 接 `web/src/editor/mapcommands.js`、`server/{mapworkspace,copyprofile}.js` 與 `editor-ui/src/{gamemapworkbench,mapcanvas}.js`、現有地圖面板。北側先只准縮**空白新增帶**；有物件明確拒絕，留 E4 實作。預演／確認／取消／撤銷／儲存後重讀都走正常 copy 路徑。此關開的是可編輯，不是可發布；不得啟用退役 Trial API。
- **出口順序**：單元 → 隔離真 HTTP／SQLite → 全新瀏覽器實際按鈕 → 已核對的目前副本。北加後 minY 減一，原城路世界座標不變；取消不改、撤銷復原；儲存重開仍在，縮回再存後語義與基線相同。至少檢查兩邊界的渲染與拾取；舊頁面快取、假載入或只改 DOM 不算。此步應讓使用者看到成果，不等發布關才接頁面。

### E3｜補齊四側八個控制與可逆組合
- 將同一操作參數化，不複製四份裁切邏輯。補東西南控件、額度、預覽、確認、卷動／縮放後命中與錯誤訊息。空白帶寫入使用同一條服務命令；所有方向仍拒絕破壞性裁切直到 E4。
- **出口**：每側 0→1→20→拒第21→0→拒負數；交錯西北擴後縮東不合法，南北不互借；兩種操作順序得相同範圍及內容；重開後數值不重設。最大尺寸四角不跳座標、按鈕未遮住小地圖。每一方向至少一次頁面點擊，不只測共用函式。

### E4｜含物件裁切與錯誤修復
- 盤點 `componenttools`、`mapobjectmove`、`mappositionvalidation`、底層 unknown、水域群組、碼頭／門、道路與章節鄰接。依合同產生確定的影響清單，未能處理的引用拒絕。完成批次預演、修正回饋、一次撤銷與正常保存。
- **出口**：中心未越界但足跡跨界的多格裝飾、恰貼邊但未相交的裝飾、城綁定、只剩一端的路、中段穿出又穿入的路、多章同城、同格疊加各有斷言；取消／整批失敗不變，撤銷還原完整 ID 與資料。越界路不可尋徑；重新放置／綁城及顯式修路後紅錯消失，保存重讀與全量檢驗分別測試。破壞性案例只用隔離夾具。

### E5｜模板、建立、複製與服務端保護
- 沿用 `server/{systembasemap,systembasemapstore,gamecopy}.js`，兩種建立入口從同一已驗證快照物化，不建另一個管理頁。模板若提供編輯亦用既有管理員「基礎地圖」與共同命令；只在隔離庫驗此路。遊戲工作台不授予模板寫權。
- **出口**：例如模板北已加12，新建與完整複製僅能再加8；模板修改不追改兩份既有地圖、修改其中一份亦不影響另一份。空身分、越權作者、偽造方向／邊界、錯 epoch、超預算、執行中失敗與重讀皆檢查資料不被覆寫；不建立第二個現場完整副本。舊固定圖與老快照仍可讀。

### E6｜共同編譯、玩家包與全圖顯示
- 從 `trialcompile.js`、`tilepixels.js`、`web/src/player/{playerpack,playerenvironment}.js`、`worldresources.js`、`render/{mapview,chunkedterrain,minimapmarkers}.js` 追查。尺寸、原點、路圖、地形、四季資源、產出摘要與版本一致；不靠單一 `northExperiment` 通行。分清規則層、視圖、圖集與命中；小地圖導航、點城、拖曳、路點標記、視口裁切同座標。先以本地包驗，不開正式發布端。
- **出口**：原域逐格／規則等價、每側新城與道路可編譯、最大尺寸每角可見可點、縮放後大小地圖互指同格，西北負格不映射到末列；四季共享布局且切季無跳位。少資產、錯 digest、錯 bounds、壞路拒絕。記錄同機原圖／最大圖編譯耗時、峰值記憶體及頁面互動，不能靠無界全圖每幀重算。

### E7｜同一策略引擎的玩家與 NPC 行軍
- 將實驗 `worldgridroads`、`navigation/`、`ai.js`、`scenarioassembly.js`、`gamebar.js` 接回共同命令、派令／調度與規則讀取，不留只能玩家單軍友城往返的捷徑；Web 的城、路、路點與占格用穩定身份，不以 DOS 指標或把座標截成 byte 模擬。舊域以原證作對照，未知保持拒絕，不隨意換成 A* 或猜 RNG。
- **出口**：北平到北側遼東、南側交州及西／東路跨界；新城路必須真正建置、綁戰場、各章准入。玩家下令、NPC 自主派令、委任、改令折返、多路選擇、占格衝突、無路不可達均驗。記錄起／終、每個到期步、游標、占格、規則時序與 RNG；不得直接把軍團位置寫到終點。原圖策略、行軍與命令優先權回歸。

### E8｜接敵、攻守與戰後跨界接續
- 追查行軍→野戰／攻城→快算或戰術→勝負返回→撤退／續進、易主、補兵與每日／月度調度。使用原證與既有戰場綁定，地理顯示不是戰場機制。擴展格不能被原固定行位址錯讀；保持事件順序、hold、勝敗與 RNG 消耗。
- **出口**：擴展區敵我接敵、城防／戰場可載、戰術與委任返回、勝敗／撤退、城損及所屬寫回、跨日月後軍費／士氣與事件無重派。相同種子及同構局在舊域比對規則消費；未閉合的戰鬥分支列缺口，不准以「友城可到」放行。

### E9｜完整存檔、標題恢復與相容
- 擴展 `scenarioassembly.js`、`savegame.js` 與既有 IndexedDB 合同；保存／驗證版本、世界與章節身份、邊界、路圖摘要、路點方向、全體占格、時鐘、事件、RNG、戰略狀態。先 detached 驗證再安裝，只允許從標題讀，不熱換當局。不得把實驗 JSON 當正式快照。
- **出口**：全新隔離 profile，用玩家實際流程在 `y=-1` 及西側負 X 行軍中存→回標題→重載；與不中斷對照直到抵達／後續日月，同步逐步驗軍團、占格、結果與 RNG。錯遊戲／版本／邊界／摘要、損壞游標、失敗交易、跨視窗衝突、未完戰事禁存；拒絕不得刪舊檔。原固定版存讀另跑。

### E10｜本地發布閉環、清理與交付
- 前九關全過才對新版本精確調整 `server/playpacks.js` 等正式包准入。用**隔離**作者與管理員走 copy→全量檢驗→一次性票→提交→審核→formal→玩家目錄選擇→新局、跨界、讀檔。負例保留正式拒絕；已發行舊包／內置身份不改。不得改線上資料或以本輪上架目前副本。
- 逐一處置實驗旗標、暫時出口及固定尺寸的舊測：保留合法的相容／拒絕測試，把已取代的實驗測試改為新正式測試或有理由地退役；不可讓整條測試依賴實驗旗標。更新長期合同、適用 SKILL 與歷史 journal，實作收據連回本目錄。詳見驗收帳。
- **出口**：原圖、北線、南線、四邊滿額與錯誤資料矩陣全數有結果；既有副本可透過現有頁面使用而不重拷，現場還原核對完成。未跑／失敗／須部署許可逐項列示；外部部署不屬本地結案定義。
