**狀態：E0–E10 本地隔離驗證完成（未部署）。** 開始點是現有可編輯遊戲副本、現有「遊戲地圖」工作台；終點是用同一套編輯／編譯／玩家引擎，在四向延伸的地圖建城接路，可行軍、作戰、存讀並通過本地發布鏈。E10 收據與阻塞清單見 `acceptance.md`；瀏覽器正式鏈、頁面級既有副本使用與部署待擁有者會話／授權。不是把北線實驗按鈕公開，也不是另寫一個地圖頁或第二套簡化遊戲。本文是 Web 產品計畫，不是 DOS 機制原證。

**地圖管理與基礎地圖共用的增長方式（Web 產品決定）**：管理員可在「基礎地圖」使用相同的四向擴縮；保存只更新系統模板，既有遊戲不跟隨變更。四個「增」按鈕明確送出 `fill: 'edge'`，逐格延伸當下最外側的普通地形與裝飾疊層；只取跨格素材的邊線，不複製道路、橋、城門、據點及其綁定。新增單格獨立可改，原座標不變，一次按鈕操作可一次撤銷。全海基底仍是全海；舊無 `fill` 命令仍按原合同擴出海底，不追改既有地圖。縮回規則不變。
