## 開發批次交接（下列為部署前的驗證紀錄）

基礎地圖與遊戲地圖管理已共用單格編輯、撤銷、路城校驗與保存重讀；單格編輯源可編譯發布，新程式也可讀取已驗證的舊發布包。**此批僅交付程式、轉換工具及驗證，沒有部署，也沒有批次轉換生產模板或既有遊戲。** 提交前覆核：60 項地圖／素材庫／保存回歸通過，Vue LSP 覆蓋 37 個 SFC，編輯器產物與 Trial bundle 和來源一致。

### 決策與排障

| 問題 | 原因、修正與驗證 |
| --- | --- |
| 分層模板接近 64 MiB，保存可能回 413 | 不提高上限。轉換器讀取已保存的源，保留每格最終素材、規則地理、小地圖地理和道路；空格與明鋪 95 分開。首個無 policy 的舊 copy 被拒；僅在確認其底層逐格明確為 95 後才支持轉換，不猜未知底圖。 |
| 轉換後選區失效、放手仍選在原處 | 舊手勢找實例 ID，單格改按座標操作。移動原件與 Shift 複製裝飾分開；中心保留綁定，搬移同步主表及章節座標，不連帶搬城門。隔離 Chromium 驗過單／多選、拖放、撤銷、落點及保存重讀。 |
| 北平—右北平路紋已補，仍報孤立；有旁路時，斷路反而存得下 | 刪格會移除舊邊，補磚原本不重建；只查城市互達又會漏掉殘磚。現在以最終格面認證唯一門到門路段，更新章節鄰城；碰路城即檢查路段覆蓋與整網，失敗標紅、回 422 且不部分寫入。已綁定但完全無路的據點可保存，不等於允許殘段。純裝飾不觸發連通校驗。 |
| 工作台回饋與素材辨識 | Ctrl+Z 等同撤銷，輸入框例外；保存結果使用只可「確認」關閉的對話框。移除裸底標籤與格子懸停長提示，保留蒙板與無障礙說明。原版 `MMAP.MAP` 解碼與 `web/mmap_map.bin` 一致：177 出現 1008 格，72／190 為 0。依使用者決定僅隱藏 72／190 卡，保留 177；238 張單格卡＋4 組，256 個素材身份及舊圖不變。 |

### 驗證收據與邊界

- **轉換**：唯讀 dev 模板 v223（464×336）地圖＋定義／組合 JSON 64,530,600 → 單格地圖 884,224 bytes；遊戲 copy（384×264）58,480,487 → 666,109 bytes。兩份樣本各 195 城／258 路，逐格比對地形、規則地理、小地圖地理及路徑 mask；另比對 19 章編譯結果。這是**地圖資料大小**，不是整個遊戲包大小或玩家載入耗時。
- **編輯與持久化**：單格校驗、斷路／修復、裝飾保存分流批次 55 項通過；後續路城拖移及無路據點批次 42 項通過，含隔離 SQLite 保存重讀。基礎地圖 `--single-cell`、遊戲地圖 `--edge-growth` 分別驗過快捷鍵／保存彈窗；後者不是單格擴縮測試。素材庫批次 37 項及 build/check 通過。Vue LSP 有批次結果，沒有覆蓋全部變更 JS 的 LSP／Lens 結論；上述不是本次文檔整理重跑的成績。
- **新包發布與實玩**：192 城樣本與唯讀匯入的 dev 195 城／19 章副本，在隔離 HTTPS 編輯器轉換、改格、送審及批准。首次補路全鏈測試遇 `ECONNRESET`，測試端改用獨立連線後通過，未重送正式寫入。正式 reader 驗過前兩章新局、追加保存及跨章讀回；195 城包另核北平—右北平 19 格路線與鄰接、《呂布歸天》行軍接戰及《隱伏新野》月結。不是全戰役驗收。
- **舊包相容**：候選程式另讀 dev 已上架 1.7 原包，未轉源、未重發；隔離瀏覽器驗前兩章開局及存讀。生產 1.0 實際包、升級前已有玩家存檔未測，不能以 dev 結果代替。

**相關入口**：`web/src/content/authoring/{cellmap,cellplane,mapcompile}.js`（格式／編譯）；`web/src/editor/{roadchain,mappositionvalidation}.js`（成路／診斷）；`editor-ui/src/{BaseMapPanel.vue,mapcanvas.js,basemap.js,mapatomiccatalog.js}`（工作台）；`server/{mapworkspace,copyprofile,gamecopy,systembasemapstore}.js`（命令、權限與寫入）。隔離驗證入口及命令見[專案記憶 §5](../AGENTS.md#5-常用命令與分級驗證)。
