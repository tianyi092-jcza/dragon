## 一、项目概览（稳定事实）

- **目标**：Web 复刻 DOS 经典《臥龍傳》（1995）。原版二进制在 `E:/Dragon/Dragon/`：KI.EXE（主程序 66KB）、MMAP.MAP/.MDL/.MCH（地图/tile/旗帜）、GAMEPAL.BRG（4季×16色 6-bit）、sinario.dat（剧本）、SAVE.DAT。
- **Web 端**：`E:/Dragon/web-port/web/`，原生 JS + Canvas，无构建。`data.json` = 20 剧本解析结果（城池含 type 0-5）。
- **原版显示模式**：VGA mode 0x12（640×480 16 色，`mov ax,0x12; int 0x10` @KI.EXE 0xEB6C）。
- **代码索引与快速查找**：项目已配置并运行 CodeGraph 索引插件（SQLite FTS5 + WAL，112 文件 / 799 节点 / 1815 边），支持 `codegraph_search` / `codegraph_callers` / `codegraph_impact` 毫秒级符号与调用链定位。
- **逆向工具**：`web-port/tools/disasm.py`（capstone：`func(addr,len)`、`callers(addr)`）；`render_map.py` 提供 `load_palette(bank)`/`load_tiles()`（**返回 list[256] 非 dict**）。
- **时钟**：`game/clock.js`，1 tick=1 时刻（0-23），24 tick=1 天；速度档 [0,512,256,96] ms/tick（中速≈6.1 秒/天）；换月调月度结算。
- **军师菜单交互规范与全局约束（2026 最新用户定稿）**：
  1. **羽扇图标一级乒乓开关**：羽扇图标为全局乒乓开关，隐藏时强制关闭所有子孙弹窗与选中状态并恢复计时；能关闭军师菜单的**只有再次点击羽扇图标**；
  2. **单选互斥与绝对锁定**：8 项子菜单（進言、人事、財政、編成、軍團、據點、武將、勢力）严格单选。任意子项被打开时，大地图全局锁定（不可拖拽平移，地图交互拾取全部失效），其余 7 项子菜单不可点击且无悬停高亮；
  3. **严格右键回退与无关闭按钮**：全游戏无任何 UI 关闭按钮，所有弹窗与二级菜单只能通过鼠标右键回退关闭。第 1 次右键关闭子弹窗并取消子项选中状态，恢复未选中并立即开始计时（`clock.hold=false`），菜单条保持展开；再次右键关闭军师菜单条；
  4. **地图左键纯粹性**：除据点中心与行走军团外，点击地图空白/山川/河流没有任何功能，不关闭弹窗/菜单。

## 二、本轮目标与已完成工作汇总（2026-08-28）

### 1. 军师进言「請求君主出陣」机制逆向实锤与修正 (`KI.EXE 0x699E-0x6A10`, `0x3B08`)

- **出阵与信赖度完全无关（不增不减）**：
  - 反编译底层汇编证实：同意出阵调用 `0x6E8F` 扣兵生成军团驻守首都，调用 `0x5E80` 刷新预备兵，**信赖度不增加（0 变动）**；拒绝出阵仅展示拒绝发言（Talk 403..405），**信赖度不扣减（0 变动）**；全程无信赖度惩罚或奖励；
- **君主拒绝出阵的双重客观判定**：
  - 条件 1（资金门槛 `0x69B6-0x69CE`）：国库非赤字且资金 $\ge (15 - \text{bellicosity}) \times 400$ 金（好战度越低资金底线要求越高）；
  - 条件 2（预备兵门槛 `0x69D2-0x69EC`）：势力预备兵总数（骑+步+弓）$\ge 6000$ 兵；
  - 只有双重条件均满足时君主才同意出阵。

## 三、关键决策与设计约定

1. **军师菜单交互最高优先级**：羽扇图标为军师菜单唯一开关；点击羽扇关闭时强制清除所有子孙弹窗与选中状态并恢复时钟计时。
2. **绝对单选与地图锁定**：军师子菜单（進言/人事/財政/編成/軍團/據點/武將/勢力）处于激活状态时，大地图绝对锁定不可拖拽不可拾取；只有通过右键逐层回退至全未选中状态后才恢复地图操作。
3. **全游戏零关闭按钮**：所有弹窗与二级菜单均通过鼠标右键回退关闭。
4. **数字字体统一**：全局纯数字统一切换为纤细典雅的 `300 16px "Oswald"`（`Oswald-Light.woff2`）。
5. **底部提示框统一规范**：宽度 480px、高度 5 tiles（80px），屏幕水平居中、底对齐留白 8px；统一使用 `web/grf/ui/message_npc.png`（64×64）。

## 四、失败尝试与设计禁区（勿重复）

1. **`openListDialog` 回调命名**：规范参数是 `onPick: (rowIndex) => {}`，先前误写为 `onPickRow` 导致点击行无响应。
2. **出阵信赖度臆测**：曾误以为君主出阵/驳回出阵会增减信赖度（+10/-20），经底层反汇编 `0x699E` 和 `0x3B08` 确认出阵完全不影响信赖度。
3. **小地图底纹**：底纹是 VGA 16 色时代程序化逐像素抖动，不是贴图精灵，不可用单色暴力替换。
4. **全游戏绝不允许添加任何 UI 关闭按钮**。
