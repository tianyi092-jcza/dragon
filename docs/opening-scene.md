# 开场场景（Web 产品决定，非原版机制）

## 维护位置与来源

唯一运行/维护目录是 `web/intro/`：`app.js` 生命周期与音频，`music-cache.js` 音乐完整下载/缓存，`timeline.js` 原生RAF时间轴，`intro.config.js` 文字/音乐配置，`scene.html` 场景结构，`styles.css` 独立表现，`assets/` 六份实际使用资源。

来源为用户提供的 `F:/dragon/wolong_intro_vite`。素材按原文件复制；F盘原项目保留备份。构图及动画参数从其 `app.js` 移植：1920×1080设计坐标（原contain已被下述覆盖策略替代），远景0–6秒渐显、4–28秒上移352→43，前景4–24秒下移470→594，标题16–20秒、副标题20–22秒、页脚22–24秒淡入，31.55秒终场。插值为 sine.inOut。无需 Vite、GSAP、PixiJS、npm或CDN；只部署完整 `web/`。

## 视口适配（用户确认方案2）

背景以左上角为原点，不平铺、不缩小；比例为 `max(1, 窗口宽/1920, 窗口高/1080)`，必要时等比放大覆盖窗口。超出右侧/底部的内容裁切，页面不出现滚动条。1920×1080视口为原尺寸；同宽非全屏因浏览器工具栏减少高度时，只裁切底部，不缩小、不居中留边。更小窗口会看到原构图的局部，这是保持不缩小的预期行为。画面本身的白色天空不属于适配留白。

只变换背景场景，既有640×400弹窗继续屏幕居中，页脚与右上控制按钮仍按窗口定位。

## 版权说明配置

页脚统一使用 `intro.config.js` 的单个 `footerText` 字符串，一个 `<br>` 分出两行：原版版权及章节/音乐来源；用途与权益说明及在线体验/代码仓库/联系邮箱。文字按用户提供内容显示；只将 `<br>` 转为换行节点，其余保持文本，网址和邮箱同样保持纯文本，无链接属性和点击跳转，不解析任意HTML。说明框始终占页面宽度80%，圆角5px；窄屏仍允许自然折行，避免内容溢出。不再识别或生成任何链接。

行间额外空隙由0.8em减为0.4em（移动端0.7em减为0.35em）；内边距由12×22px减为6×11px（移动端10×14px减为5×7px），底边基准距离24px减为12px，保留安全区。

## 用户确认的入口约定

- 首次进入当前标签页播放开场；“三国制霸之计”副标题完全显现后，才放行现有首个“是否新游戏”弹窗。门控直接绑定副标题透明度达到1（当前时间轴第22秒），替代旧15秒门控。
- 提前跳到最后，先显示完整副标题并立即放行弹窗；弹窗已出现后跳过不影响当前弹窗/选择。
- 弹窗保持原Canvas 640×400及现有大小、居中、金框/云纹、鼠标/右键与自定义军师输入。不随背景设计坐标缩放。
- 背景重启按钮清除会话标记并整页reload；即使已在弹窗/加载中也从头开始。音乐按钮只控制开场音乐。
- 普通刷新、结束游戏后的reload进入终场静态人物、不自动播放音乐。游戏内读档经现有 `returnToTitle(1)` 进入终场并显示存档弹窗；取消后仍沿用既有回退流程。
- 网页无法可靠区分普通reload与Ctrl+F5。用户接受 `sessionStorage['wolong.intro.seen.v1']` 替代：同一标签页刷新不重播，明确“重新开始”按钮才重置。浏览器复制标签页可能继承sessionStorage；存储不可用时降级为首次访问行为。
- 开场播放时间在后台暂停，不计隐藏时长；恢复只继续活动标题场景。系统减少动画时，在资源就绪/音频启动后直接终场并放行。

## 音频与游戏边界

`opening.mp3` 音量0.82，单次播放，不循环。跳过同时停曲、静音并归零，只影响开场。独立开场静音不写游戏 `MusicPlayer.type`。

### 首次加载与缓存（用户追加要求）

- 白色空白页中央显示标准原生 `<progress>`，最大宽320px，按窗口居中，不随1920×1080场景缩放。音乐按实际下载字节更新百分比；服务器没有可靠的 `Content-Length` 或使用压缩传输时，显示不定进度及已收KB，不伪造百分比。写缓存阶段保持99%，完成后才100%。
- 必须完整下载MP3、等待缓存写入结束、确认音频可播放及图片解码完成，才启动开场。不再使用旧的“最多等待4秒便播放动画”逻辑；副标题显现及弹窗门槛从实际动画开始计时，不含加载或等待用户点击的时间。
- 同源 Cache Storage `wolong.intro.music.v1` 保存完整音乐，后续优先读取，无须再次网络请求；缓存键是带内容版本的完整URL。`intro.config.js` 当前版本查询值 `2f00b4805ba824ab` 来自MP3 SHA-256前16位，更换音乐时同步更新；不删除其它资源缓存或游戏IndexedDB。
- 播放器使用完整Blob URL，销毁时撤销。普通刷新仍直达无声终场，不为静态终场下载音乐；明确重启或再次首播复用缓存。音乐缓存不是整站离线支持，图片/页面仍遵循原HTTP加载。
- 缓存不能解除浏览器自动播放限制：允许自动播放时直接开始；被拒绝时画面/时间轴留在起点，中央显示“点击开始（开启声音）”，点击或键盘激活后才一起启动音乐和动画。也可用现有静音按钮明确选择无声开场，或用跳过直接终场。
- Cache Storage 需要HTTPS或localhost等安全上下文，也可能被浏览器禁用、配额限制或清理。不能持久保存时只使用本次完整内存Blob，并如实提示，不声称下次无需下载；缓存被清理后自动重新下载。
- 下载/解码超时或失败进入开场错误提示并放行游戏选择，不将失败伪装成加载成功，不把半份音乐写入缓存。音乐准备总超时60秒、Blob媒体解码等待上限30秒；超时不是“带着未加载音乐开始动画”。

`ScoreDirector.title()` 选择null，避免旧标题FLAC与MP3重叠；进入地图后原四季/交涉/战斗/失败选曲及音效保持原管理。原版标题选曲0的证据仍有效，但不再作为此Web标题的产品行为。

启动先取得既有浏览器单实例锁，才挂载开场/装配App；`menuReady` 仅控制首个弹窗，地图与战斗资源仍在确认新局/读档之后加载。`enterGame` 成功后停止开场RAF/音频、将GIF换静态图、隐藏整个标题。返回标题复用已挂载场景，不产生第二个播放器或RAF。装饰图片加载失败显示提示并放行游戏选择；结构文件或应用初始化失败由既有boot错误提示处理。

背景、弹窗与按钮使用分层显示；背景按钮在小窗口也能命中，除重启外不能改变弹窗状态。正式存档保持原同源IndexedDB四槽，不涉及DOS存档。
