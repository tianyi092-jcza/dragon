## 2. CDE参数化端口合同及原指令

```text
CDE PUSH AX; AX=0101h; CALL EB11; POP AX; RET
EB11 PUSH CX; CX=AX
  等3DA.bit3=1
  AL=IN61; OUT61(AL|3)
  依次等3DA.bit3=0、1、0、1
  AL=IN61; OUT61(AL&FCh)
  CMP CL,1; JE EB5C
  [其它参数时才执行EB40..EB5B次数循环]
EB5C POP CX; RET
EB5E PUSH DX; DX=3DA; IN AL,DX; POP DX
  TEST AL,8; 按结果STC/CLC; RET
```

本批只在原IN/OUT地址EB1B/1F/35/39/62提供外部合同：3DA与61的读取逐次取保存的byte序列，OUT保存地址/值。原CALL/PUSH/POP/所有循环和FLAGS照字节执行，无规则/声音callee替身。两次61输入独立，不假定原机输出自动变成下一输入。
