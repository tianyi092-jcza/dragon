# 军团/战斗流程规格（用户 2026-09 提供原版 12 张截图实证）

## 完整流程

1. **編成**（顶栏菜单 軍團）：武将列表（武將名/武力/統率/政治/勢力/身分）选将 →
2. **兵力分配弹窗**：将军头像+将军名+總兵力(6000)+士氣值(200)；主將/前鋒/左翼/右翼/左備/右備 各 1000（带兵种小图标）+ 預備兵數 騎2000/弓2000/步2000；确定 →
3. **出陣确认**：军师头像+「遵命！各位！出陣了！」→ 军团出现在城市（旗帜图标=君主姓名+势力颜色，如「回[曹操]」）
4. **地图交互**：鼠标光标=圆角方框线框（大小=据点建筑），只有线框对准据点建筑点击才触发：
   - 弹窗两选项：**據點** / **軍團**
   - 據點 → 据点信息面板（城名/归属/君主/城兵數/生產力/上昇值/耐久值+风景图）
   - 軍團 → 该据点军团列表（武將名/總兵數/士氣值/現在位置/目標據點）
5. **双击军团** → 「請指示軍團目標之據點」→ 点击目标据点 → 模式选择：**戰鬥指揮** / **委任**
6. **委任**：军团沿道路走向目标并自动攻击，**不进战斗场景**，速算胜负（战败/攻下据点）
7. **戰鬥指揮**：中途遇敌 → 遭遇弹窗「XX大人的兵馬，遇上YY的兵馬了！！」→ 进入战斗场景：
   - 全屏战术地图（地形随地点不同：陆地/水上战场各异——需逆向战场选择）
   - 右侧面板：陸上|作戰 / 攻方名|守方名 / 陳登軍(守)横幅+小地图 / 夏侯惇軍(攻)横幅
   - 下方命令钮：突擊/攻擊/陣形/城壁/守備/撤退（=逆向出的 6 个 48×16 命令钮 cmd0/1/2/5/右键×2）
   - 单位小图标网格（组/单位状态）
   - 胜负=场所值（士气）低者败
