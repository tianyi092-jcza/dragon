## 交付边界

- 地图/章节展示重构不实施；已关联武将的旧章级名称/画像覆盖由服务端拒绝，提示到武将库修改。主表删除留下缺失引用，由发布门报告，不隐式免职。
- 实现阶段未部署、未重启用户服务、未删除真实游戏、未自动迁移已有copy/publish/formal；后续授权的本地孤儿文件清理见下条。现已获用户授权纳入journal§58统一审查提交／推送，仍不授权部署或迁移。
- 用户先通过更新后的管理入口彻底删除旧复制游戏，确认资料列及存储回收均完成，再重新复制测试。用户确认本地并要求残留全部清除后，两份旧副本孤儿文件均已按gameId核验并清除，合计98文件约96MB，实际私有目录为空，共享资源未变，详见journal§54后续。代码修复本身不自动清理历史垃圾。
- 浏览器API为隔离内存夹具；真实HTTPS链使用独立临时SQLite/FileBucket及已登记固定源。两者不等同生产验证，也未执行玩家存档/整局游玩。
